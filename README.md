# optXcurrency

Feasibility of cross-currency option structures on Deribit: short options on the currency with the higher implied
volatility premium (XRP), hedged with options on another currency (BTC). Results and method are in
[documents/](documents/README.md); start with [documents/SUMMARY.md](documents/SUMMARY.md).

Run code with this project's own virtual environment: `.venv\Scripts\python.exe` (Python 3.12,
`requirements.txt`). Shared datasets are read in place from `C:\ClaudeSandbox\shared-data\` (read-only).
